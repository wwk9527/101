### 263A. Beautiful Matrix



https://codeforces.com/problemset/problem/263/A

思路：

##### 代码



```
def beautiful_matrix():
    matrix = []
    for _ in range(5):
        row = list(map(int, input().split()))
        matrix.append(row)
 
    one_row, one_col = None, None
    for i in range(5):
        for j in range(5):
            if matrix[i][j] == 1:
                one_row, one_col = i, j
                break
 
    moves = abs(one_row - 2) + abs(one_col - 2)
 
    return moves
 
# 输出结果
print(beautiful_matrix())
```

### 1328A. Divisibility Problem



https://codeforces.com/problemset/problem/1328/A

思路：

##### 代码



```
def solve(a, b):
 
    moves = b-a%b
 
    return moves
 
 
# 获取测试案例的数量
t = int(input())
 
# 获取测试案例的数据
data = []
for _ in range(t):
    a, b = map(int, input().split())
    data.append((a, b))
 
# 处理每一个测试案例
for a, b in data:
    if a%b == 0:
        print(0)
        continue
    else:
        result = solve(a, b)
        print(result)
```

### 01922: Ride to School



http://cs101.openjudge.cn/practice/01922/

思路：

##### 代码



```
import math

x=4.5
T = []
while True:
    n = int(input())
    if n == 0:
        break
    else:
        v_t = []
        for i in range(n):
            v, t = map(int, input().split())
            if t >= 0:
                v_t.append(math.ceil(x * 3600 / v + t))
            else:
                continue
        T.append(min(v_t))
print(*T, sep='\n')
```
